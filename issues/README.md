# Local issue tracker

- Each feature lives at `issues/<feature-slug>/` and may contain a `PRD.md` plus numbered issue files under `issues/`.
- Each issue starts with `Status: <state-label>` and `Category: <category-label>`.
- Valid state labels are `needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, `in-progress`, `done`, and `wontfix`.
- Valid category labels are `bug` and `enhancement`.
- Comments are appended under `## Comments`. Every AI-authored comment starts with `[AI-authored]`.
